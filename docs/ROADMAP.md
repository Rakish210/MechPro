# MechPro – Development Roadmap

## Phase 1: Foundation
- [x] Establish repository structure and product principles
- [ ] Create React + TypeScript frontend
- [ ] Create Python + FastAPI service
- [ ] Add automated checks and a smoke test
- [ ] Add Tauri desktop integration

## Phase 2: Project workspace
- Project list and creation
- Building, floor, and room data
- SQLite persistence
- Project import/export and backups

## Phase 3: Shared engineering foundation
- Units and conversions
- Materials and component catalogs
- Reusable flow, velocity, pressure-drop, and capacity primitives
- Calculation provenance, assumptions, warnings, and reference metadata

## Phase 4: First discipline modules
1. Plumbing
2. Heating and cooling
3. Ventilation

Each module requires reviewed calculation specifications and reference test cases.

## Phase 5: Additional systems
Fire protection, natural gas, smoke control, compressed air, vacuum, medical gases, steam, condensate, and process systems.

## Phase 6: Deliverables
Quantity takeoff, equipment schedules, cost estimates, PDF, spreadsheet, and document reports.

## Phase 7: Optional online services
Cloud AI assistant, online catalogs, updates, and optional team synchronization.

## Phase 8: Distribution
Community and Professional editions, license review, installers, signing, updates, and releases.
